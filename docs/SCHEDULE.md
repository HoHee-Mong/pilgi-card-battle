## 통합·테스트 계획
- 매일: 각자 PR merge → `main`에서 앱 실행 확인
- 1차 통합(1주차 말): 카드 생성부터 방 공유까지
- 2차 통합(2주차 말): 투표 → 모의고사·배틀 → 오답 노트까지 전체 흐름, 기기 2대
- 3주차: 기능 동결 후 버그만 수정
- 체크리스트: 카드 생성 실패(악필·빈 페이지), 검수 안 한 카드가 문제은행에 안 들어가는지, 투표 중복·취소, 투표 순서대로 모의고사가 구성되는지, 배틀 중 상대 나감, 동시 제출, 오답이 노트에 들어가는지, 사운드 끄기
