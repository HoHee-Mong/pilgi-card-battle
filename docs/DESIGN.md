# 디자인 규칙 — "형광펜과 볼펜"

목표: AI가 만든 티 없이, 토스·애플처럼 여백 넓고 타이포가 강하며 모션이 스프링처럼 부드러운 앱.
시안: 디자인 캔버스 "필기 카드 배틀 디자인" (홈 / 카드 공개 / 족보 노트 / 스터디 방)

## 금지
- 그라데이션 배경, 이모지 아이콘, 왼쪽 컬러 테두리 카드, 그림자 남발, 기본 Material 파란 버튼
- 화면마다 다른 색 추가. 포인트 색은 아래 두 개뿐

## 색 (`lib/core/theme/tokens.dart`)
| 토큰 | 값 | 용도 |
|---|---|---|
| bg | #F4F5F7 | 기본 바탕 |
| surface | #FFFFFF | 카드·리스트 면 |
| ink | #17181C | 본문·주요 버튼 |
| inkSub | #5B6170 | 보조 텍스트 |
| line | #E6E8EC | 구분선·비활성 |
| blue | #2F5BFF | 볼펜 파랑, 주요 동작·내 정보 |
| blueText | #2447CC | 흰 바탕 위 파랑 글자 |
| lime | #D7F54A | 형광펜, 강조·정답 (글자는 항상 ink) |
| wrong | #FFDDD6 | 오답 배경 |
| dark | #14151A | 몰입 화면 배경 (카드 공개) |

## 타이포
- 폰트: Pretendard (없으면 Noto Sans KR)
- 제목 28~36 / w800 / 자간 -0.8~-1.0
- 본문 15~16 / w500 / 줄간격 1.5
- 보조 13~14 / w500 / inkSub
- 핵심 단어 강조: 글자 아래 절반에 lime 형광펜 (배경 하이라이트)

## 형태·간격
- 좌우 여백 20, 섹션 간격 22~24
- 라운드: 카드 24, 버튼 18, 칩 15, 원형 아이콘 버튼 22
- 터치 영역 최소 44

## 모션
- 기본 커브: 스프링 `Curves.easeOutBack`에 가깝게, 과하지 않게 (overshoot 살짝)
- 버튼 눌림: scale 0.96, 280ms, 손 떼면 스프링 복귀 → 공용 `PressableScale` 위젯
- 화면 전환: 오른쪽에서 밀려오기 + 살짝 페이드 (iOS 느낌)
- 카드 뒤집기: Y축 회전 800ms, 원근감(`Matrix4..setEntry(3,2,0.001)`)
- 점수 막대: 900ms 스프링
- 정답: lime 배경 + 짧은 진동(`HapticFeedback.lightImpact`) + 효과음
- 오답: wrong 배경 + `mediumImpact` + 효과음
- 리스트 등장: 아이템마다 40ms씩 늦게 페이드+위로 8px

## 사운드
- 짧고 작게(볼륨 0.6 이하). 정답·오답·카운트다운·결과 4종이면 충분
- 설정에서 끌 수 있게
