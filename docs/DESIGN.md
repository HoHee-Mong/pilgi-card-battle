# 디자인 규칙 — "시험지 보스를 잡는 아케이드"

목표: 공부가 게임처럼 느껴지는 화려하고 손맛 있는 앱. AI가 만든 뻔한 앱처럼 보이지 않게.
시안: 디자인 캔버스 "필기 카드 배틀 디자인"의 아래 줄 **게임 버전** 4화면
(GLobby 로비 / GBank 예상 문제 랭킹 / GExam 모의고사 보스전 / GResult 보스 격파 결과).
위 줄(흰색 미니멀 버전)은 폐기안. 참고하지 않는다.

## 핵심 스타일: 블록(Chunky) UI
- 모든 카드·버튼: **3px 진한 테두리(ink) + 아래로 6px 딱딱한 그림자**(`BoxShadow(offset: Offset(0, 6), blurRadius: 0)`)
- 누르면: 위젯이 4px 내려가고 그림자가 2px로 줄어든다 (120ms) → 공용 `ChunkyButton`
- 그라데이션, 흐린 그림자(blur), 이모지 아이콘 금지. 아이콘은 직접 그린 굵은 선 SVG 또는 굵은 아이콘 세트

## 색 (`lib/core/theme/tokens.dart`)
| 토큰 | 값 | 용도 |
|---|---|---|
| ink | #1A0B3B | 테두리·그림자·본문 글자·어두운 배경(보스전) |
| grape | #6C3BFF | 로비 배경, 주요 강조 (흰 글자 OK) |
| pink | #FF4D8D | 보스·1위·주요 버튼 (글자는 ink) |
| lime | #B8FF3B | 정답·투표 완료·성공 (글자는 ink) |
| sun | #FFD23F | 결과 배경·연속 출석·코인류 (글자는 ink) |
| cyan | #33E1FF | 보조 강조 (글자는 ink) |
| cream | #FFF1D6 | 문제은행 등 밝은 화면 배경 |
| paper | #FFF8EE | 카드 면 |

- 화면마다 배경색을 바꿔 분위기를 나눈다: 로비 grape / 문제은행 cream / 모의고사 ink / 결과 sun
- 밝은 색(pink·lime·sun·cyan) 위 글자는 항상 ink

## 타이포
- 제목·숫자·버튼: **Black Han Sans** (`google_fonts`), 굵기 하나뿐이므로 weight 지정 X
- 본문: Noto Sans KR 500/700/900
- 큰 숫자·"적중!" 같은 효과 글자: Black Han Sans + ink 외곽선(`Paint()..style=stroke`)

## 형태·간격
- 좌우 여백 18, 섹션 간격 14
- 라운드: 큰 카드 26, 버튼 22, 작은 칩 12~16
- 터치 영역 최소 44

## 게임 요소 (화면 문구)
- 다가오는 시험 = **보스** ("이번 보스: 영상처리 기말고사 D-12")
- 모의고사 = **보스전**: 남은 문제 수 = 보스 체력, 맞히면 "적중!", 틀리면 "빗나감"
- 투표 = **"나올 것 같아요"** (별 아이콘), 1위 카드에 왕관
- 결과 = **랭크(S/A/B/C)**, 최고 콤보, 획득 XP, 이번 주 **예상 적중왕**
- 레벨·XP·연속 출석·오늘의 퀘스트 (P2)

## 모션
| 상황 | 모션 |
|---|---|
| 버튼 누름 | 4px 내려감, 120ms |
| 투표 | 버튼 lime으로 바뀜 + "+1" 튀어 올랐다 사라짐(900ms) + `HapticFeedback.lightImpact` |
| 보스 대기 | 위아래로 둥둥(2.4s 반복, ±8px, ±3도) |
| 정답 | 보스 흔들림·축소(600ms) + "적중!" 도장처럼 쾅(크게→작게, 500ms 스프링) + 체력바 감소(700ms) + 효과음 |
| 오답 | 문제 카드 좌우 흔들림 2회 + "빗나감" + `mediumImpact` + 효과음 |
| 결과 | 랭크 도장 쾅 + 뒤 별 천천히 회전 + 색종이 낙하 |
| 1위 왕관 | 좌우로 살랑(1.8s) |

## 사운드
- 정답, 오답, 투표, 카운트다운, 보스 격파 5종. 짧고 작게(볼륨 0.6 이하), 설정에서 끄기
