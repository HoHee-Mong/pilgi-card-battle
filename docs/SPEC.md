# 확정 기능 명세 — 필기 카드 배틀

## 한 줄 정의
**우리가 만드는 시험문제.** 필기·강의자료·녹음을 AI가 퀴즈 카드로 만들고, 같이 공부하는 친구들이 "이거 시험에 나올 것 같아"라고 투표한 문제를 모아 **모의고사**로 풀어 보는 학습 앱.

## 기획의 출발점
같이 밤새 공부하면서 서로 "이거 나오겠다" 하고 물어봤던 문제가 실제 시험에 그대로 나온 경험. 같은 수업을 들은 사람들의 예상을 모으면 실제 시험지에 가까워진다. 이 앱은 그 예상을 모으는 도구다.

## 톤
- 앱의 주인공은 AI가 아니라 **우리(같이 공부하는 친구들)**. AI는 카드 만드는 걸 돕는 도구
- 앱 안 문구 예: "우리가 뽑은 예상 문제", "선우 외 3명이 나올 것 같대요", "우리가 만든 모의고사"
- "족보"는 실제 기출문제를 가져온다는 뜻이 아니다. **수업 자료로 우리가 만든 예상 시험문제**다. 기출로 오해되지 않게 쓴다
- 투표 수는 친구들의 예상일 뿐 출제 보장이 아니다. "출제 확률 80%" 같은 수치는 쓰지 않는다

## 대상 사용자와 문제
- 대상: 시험을 준비하는 대학생, 같은 수업을 듣는 친구 2~4명
- 불편함
  - 필기·PPT·녹음이 흩어져 있어 시험 직전에 정리가 안 된다
  - 결석하거나 놓친 내용을 구하려면 매번 같은 사람에게 부탁해야 한다
  - 혼자서는 뭐가 시험에 나올지 감이 안 오고, 같이 예상한 문제도 카톡에 흩어져 사라진다

## 우선순위
- **P1 (핵심, 반드시 완성)** · **P2 (우선순위 높은 추가)** · **P3 (여유 시 확장, P1·P2 완료 전 착수 금지)**

## 기능 목록

### ★ 핵심 차별점

#### A. "나올 것 같아요" 투표 — P1 (B)
- 스터디 방 공동 문제은행의 모든 카드에 "나올 것 같아요" 버튼. 한 사람당 카드 하나에 1표, 다시 누르면 취소
- 카드에 투표 수와 투표한 사람 표시: "선우 외 2명이 나올 것 같대요"
- 문제은행 정렬: 투표 많은 순 / 최신순 / 주차별
- 혼자 풀기·배틀·모의고사 결과 화면에서도 문제마다 바로 투표 가능 (B가 만든 `VoteButton` 공용 위젯을 A 화면에서 사용)
- 내가 만든 카드가 받은 표 수를 볼 수 있다 (기여도)

#### B. 우리가 만든 모의고사 — P1 (A)
- 스터디 방에서 "모의고사 시작" → 투표 많은 순으로 N문항(10/20/30) 자동 구성, 범위(주차) 선택 가능
- 실제 시험처럼: 전체 제한 시간, 문제 이동, 마지막에 한 번에 제출·채점
- 결과: 점수, 틀린 문제, 각 문제의 투표 수, 오답은 오답 노트로
- 혼자 푸는 모드가 기본. 같은 방 사람들의 점수 비교는 P2

### 1. 과목·주차 관리 — P1 (A)
- 과목 생성: 이름, 시험일(선택) / 주차 1~16으로 자료·카드 분류

### 2. 자료 입력 — A
| 입력 | 우선순위 | 비고 |
|---|---|---|
| 필기 이미지 (촬영·갤러리) | P1 | |
| 텍스트 추출 가능한 PDF | P1 | |
| 강의 녹음 파일 (MP3·M4A·WAV) | P2 | 파일당 길이·용량 제한, 하루 요청 횟수 제한 |
| PPTX 직접 파싱, 스캔 PDF OCR, 앱 내 녹음 | P3 | |
- 원본 자료는 **기본 비공개**. 공유는 카드 단위로 사용자가 선택한다

### 3. AI 요약·카드 생성 — P1 (A)
- 자료에서 정의·공식·비교·과정 등 핵심 개념 추출 → 핵심 요약 → 카드 생성
- 카드 유형: 객관식 / OX / 단답형, 생성 옵션: 카드 수·유형
- 카드마다 개념 태그(concept). 출력은 JSON 스키마로 강제
- 직접 문제 쓰기도 가능 (AI 없이 "내가 예상한 문제" 바로 등록)

### 4. 검수·수정·출처 — P1 (A)
- 생성 카드는 `draft`. 사용자가 확인·수정 후 **검수 완료** → `verified`
- 카드마다 출처: 자료명 + 페이지 또는 녹음 시간
- 같은 과목에 비슷한 질문이 있으면 저장 전 안내 (P1은 단순 문자열 유사도)

### 5. AI 족보 노트 — P1 (A)
- 과목별: 주차별 카드, 핵심 요약, 출처 자료 목록
- 필터: 내 카드 / 방 카드, 검수 상태

### 6. 혼자 풀기·오답 복습 — P1 (A)
- 범위·유형·문항 수로 문제집 구성 → 풀이 → 결과, 풀이 기록 저장
- 틀린 문제는 오답 노트로, 다시 맞히면 복습 완료

### 7. 스터디 방·공동 문제은행 — P1 (B)
- 방 만들기(과목 선택) → 6자리 초대 코드 → 입장
- 내 `verified` 카드를 방에 공유 → 공동 문제은행에 작성자·출처와 함께 표시
- 카드가 없는 신규 참가자도 방에 들어오면 문제은행 전체를 보고 투표·풀이 가능 (강제 교환 없음)

### 8. 스터디 방 배틀 (2인) — P1 (B)
- 대기실 → 시작. 문제는 공동 문제은행에서 **투표 많은 문제 우선**으로 뽑음
- 같은 문제 동시 풀이, 15초, 정답 + 빠를수록 고득점, 연속 정답 콤보
- 결과: 점수·정답률, 틀린 문제는 각자 오답 노트로, 문제마다 투표 버튼
- 우선 2인 안정화. 3~8인은 P3

### 9. 기본 연출 — P1 (B)
- 버튼 스프링 반응, 카드 뒤집기, 투표 시 숫자 올라가는 모션 + 진동, 정답/오답 효과음·진동, 카운트다운, 점수 막대
- 폰 기준, 태블릿에서 깨지지 않게

### 10. 녹음 → 전사·요약·카드 — P2 (A)
### 11. 교수님 강조 발언 탐지 — P2 (A)
- 전사본에서 "중요하다", "시험에 나온다" 같은 직접 발언을 시간과 함께 표시
- **AI 추정 중요 개념 / 교수님 실제 발언 / 친구들 투표**를 화면에서 구분
### 12. 즐겨찾기·취약 개념 — P2 (A)
- 개념 태그별 정답률 집계 → 약한 개념 TOP 3, 추천 카드
### 13. 모의고사 점수 비교·투표 기여도 랭킹 — P2 (B)
- 같은 방 모의고사 점수 비교, "예상 적중왕"(받은 표 많은 카드 작성자)

### P3 (확장)
- 시험 후 "실제로 나왔어요" 체크로 적중 기록, PDF+녹음 통합 분석, 근거 기반 AI 자유 질문, 3~8인 배틀·보스전, 자동 복습 추천, 정교한 중복 감지, 게임 희귀도·고대 문자 카드, 화려한 연출

## 기획상 원칙
- AI 결과를 정답으로 확정하지 않는다 → 검수 상태와 원문 대조
- 투표는 예상일 뿐 → 확률처럼 표시하지 않는다
- 원본 자료는 기본 비공개, 공유는 카드 단위
- AI 비용·시간 제한: 파일 용량·녹음 길이·하루 생성 횟수 (값은 `lib/core/config.dart`)
