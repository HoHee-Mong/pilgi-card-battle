# 필기 카드 배틀

**우리가 만드는 시험문제.** 필기·강의자료·녹음을 AI가 퀴즈 카드로 만들고, 같이 공부하는 친구들이 "나올 것 같아요"를 누른 문제를 모아 모의고사로 풀어 보는 Flutter 앱.

- 팀: 양승호(A), 장선우(B)
- 기술: Flutter, Firebase(Auth·Firestore·Storage·AI Logic/Gemini)

## 문서
| 문서 | 내용 |
|---|---|
| `CLAUDE.md` | Claude Code 작업 지침 |
| `docs/SPEC.md` | 확정 기능 명세와 우선순위 |
| `docs/DATA.md` | Firestore 구조, 공용 모델, AI 호출 규칙 |
| `docs/ROLES.md` | 역할 분담, 폴더 소유권 |
| `docs/GIT.md` | 브랜치·커밋·PR 규칙 |
| `docs/DESIGN.md` | 디자인 토큰, 모션 규칙 |
| `docs/SCHEDULE.md` | 개발 일정 |
| `docs/tasks/A.md`, `B.md` | 역할별 작업 목록 |

## Claude Code로 시작하기
1. 레포를 clone한 폴더에서 Claude Code 실행
2. 첫 메시지: "CLAUDE.md랑 docs 읽고, docs/tasks/A.md(또는 B.md)의 첫 작업부터 시작해줘"
